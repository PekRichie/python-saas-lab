# API-kulcs generátor és HMAC-ellenőrző

- **Szint:** Junior
- **Fájlok:** `app.py`, `test_app.py`

## SaaS kontextus és cél
Biztonságos, prefixelt SaaS API-kulcsok (pl. `cs_live_...`) generálása, SHA-256 hash-alapú tárolása és konstans idejű ellenőrzése.

## Futtatás és tesztelés
```bash
python3 -m unittest test_app.py -v
```
